## 1. 시작하기

### API 키 준비

앱 실행 전 아래 API 키들이 필요합니다.

| 서비스 | 용도 | 발급 URL | 비고 |
|--------|------|----------|------|
| **Alpaca Markets** | 거래·시세·계좌 | https://app.alpaca.markets | 무료 |
| **FMP (Financial Modeling Prep)** | 배당금 정보 | https://financialmodelingprep.com | 무료 플랜 |
| **ExchangeRate-API** | KRW/USD 환율 | https://www.exchangerate-api.com | 무료 플랜 |

### .env 설정

프로젝트 루트에 `.env` 파일을 생성하고 아래 내용을 채웁니다.

```env
# Alpaca (모의투자: paper-api.alpaca.markets / 실제: api.alpaca.markets)
ALPACA_API_KEY=발급받은_키
ALPACA_API_SECRET=발급받은_시크릿
ALPACA_BASE_URL=https://paper-api.alpaca.markets
ALPACA_DATA_URL=https://data.alpaca.markets
ALPACA_WS_URL=wss://stream.data.alpaca.markets/v2/iex

# FMP
FMP_API_KEY=발급받은_키

# 환율
EXCHANGE_RATE_API_KEY=발급받은_키

# Web Push VAPID (생성 명령: node -e "require('web-push').generateVAPIDKeys()")
VAPID_PUBLIC_KEY=
VAPID_PRIVATE_KEY=
NEXT_PUBLIC_VAPID_PUBLIC_KEY=
VAPID_EMAIL=admin@example.com

# 서버
PORT=3000
DATABASE_URL=file:./prisma/dev.db
```

> **모의투자 vs 실제 거래**  
> `ALPACA_BASE_URL`을 `paper-api.alpaca.markets`로 설정하면 가상 $100,000으로 연습할 수 있습니다.  
> 실제 거래는 `api.alpaca.markets`로 변경하세요.

### 서버 실행

```bash
npm install
npx prisma migrate dev
npm run dev
```

브라우저에서 `http://localhost:3000` 접속

## 3. 종목 탐색

하단 **탐색** 탭에서 접근합니다.

### 종목 검색

상단 검색창에 티커(AAPL) 또는 회사명(Apple)을 입력하면 자동완성 결과가 표시됩니다.  
결과를 탭하면 종목 상세 페이지로 이동합니다.

### 관심종목

- **+** 버튼을 탭해 티커를 입력하면 관심종목에 추가됩니다.
- 각 종목의 **×** 버튼으로 제거할 수 있습니다.
- 종목명을 탭하면 상세 페이지로 이동합니다.

### 테마별 종목

AI, 반도체, 전기차, 배당주, 클라우드, 핀테크 등 6개 테마로 분류된 종목을 확인할 수 있습니다.  
테마 카드를 탭하면 종목 목록이 펼쳐지고, 각 티커를 탭하면 상세 페이지로 이동합니다.

### 인기 종목

Alpaca 실시간 데이터 기준으로 당일 변동이 큰 주요 종목(등락률 순)을 보여줍니다.  
5분마다 자동 갱신됩니다.

## 4. 종목 상세

탐색에서 종목을 탭하거나 `/stock/AAPL` URL로 직접 접근합니다.

### 차트

| 탭 | 설명 |
|----|------|
| **실시간** | WebSocket으로 수신되는 실시간 틱 라인차트 |
| **분봉 ▼** | 1·5·15·30·60·120·240분 캔들차트 선택 |
| **1일** | 5분봉 (최근 3일) |
| **1주** | 15분봉 |
| **1달** | 1시간봉 |
| **1년** | 일봉 |
| **전체** | 일봉 (5년) |

- **마우스 휠 / 핀치**: 차트 확대·축소
- **드래그**: 차트 이동
- **크로스헤어 호버**: 날짜·O·H·L·C·거래량 표시
- 이동평균선: **5**(노랑) / **20**(보라) / **60**(하늘) / **120**(주황)

### 호가창

매수(Bid)·매도(Ask) 가격과 수량, 스프레드를 5초마다 자동 갱신합니다.

### 배당금

FMP API를 통해 최근 배당 이력과 다음 지급 예정일을 표시합니다.  
배당이 없는 종목(성장주 등)은 표시되지 않습니다.

### 매수 / 매도 버튼

종목 상세 하단의 **매수**(빨강) / **매도**(파랑) 버튼을 탭하면 주문 모달이 열립니다.  
자세한 주문 방법은 [5. 주문](#5-주문)을 참고하세요.

## 5. 주문

### 장 상태 자동 감지

주문 창을 열면 현재 장 상태를 자동으로 감지합니다.

| 상태 | 표시 | 가능한 주문 |
|------|------|------------|
| 🔴 정규장 | 정규장 | 시장가·지정가, 소수점·금액 모두 가능 |
| 🟡 프리마켓 | 프리마켓 · 지정가만, 소수점 불가 | 지정가만, 정수 수량만 |
| 🟡 애프터마켓 | 애프터마켓 · 지정가만, 소수점 불가 | 지정가만, 정수 수량만 |
| ⚫ 장 마감 | 장 마감 · 지정가 예약주문 | 지정가 예약 |

### 매수 주문

1. 종목 상세 또는 주문 탭에서 **매수** 버튼 탭
2. 종목 티커 입력 (종목 상세에서 열면 자동 입력)
3. 주문 유형 선택 (시장가 / 지정가)
4. **USD 금액** 또는 **주 수량** 선택
   - `+` / `-` 버튼 또는 직접 입력으로 수량·금액 조절
   - 기본값: 1주 가격(금액 모드) / 1주(수량 모드)
5. 지정가 입력 (지정가 주문 시)
6. **매수** 버튼 → 주문 확인 화면
7. 확인 화면에서 종목·유형·수량·예상 체결 시간 확인 후 **주문 확인**

### 장 마감 시 예약 주문

장 마감 상태에서는 체결 범위를 선택할 수 있습니다.

- **정규장만**: 다음 정규장(09:30 ET / 한국 오후 11시 30분) 오픈 시 체결
- **프리·정규·애프터 포함**: 다음 프리마켓(04:00 ET / 한국 오전 6시)부터 체결 시도

> 정규장만 선택 시 소수점·금액 입력이 가능합니다.  
> 프리·정규·애프터 포함 선택 시 정수 수량만 입력 가능합니다.

### 매도 주문 (Lot 선택)

1. **매도** 버튼 탭
2. 보유 중인 Lot 목록에서 매도할 Lot 선택
   - 각 Lot의 취득일·취득가·현재 수익률 표시
3. 주문 유형·수량 입력
4. **매도** 버튼 → 확인 화면 → **주문 확인**

> Lot이란? 같은 종목도 다른 날짜·가격에 매수하면 별개의 Lot으로 관리됩니다.  
> 어느 Lot을 팔지 선택해 세금 최적화에 활용할 수 있습니다.

### 정기 투자

하단 **주문** 탭 → **정기투자** 탭에서 설정합니다.

1. 종목, USD 금액, 주기(매일·매주·매월) 입력
2. **정기 투자 추가**
3. 활성/비활성 토글로 일시 중단 가능
4. 서버가 실행 중인 동안 설정된 주기마다 자동 시장가 매수

## 6. 포트폴리오

하단 **포트폴리오** 탭에서 접근합니다.

### 동기화

**Alpaca 주문 동기화** 버튼을 탭하면 Alpaca 계좌의 체결된 매수 주문을 모두 불러와 Lot으로 저장합니다.

### 포지션 보기

- **전체 보기**: 전체 보유 종목 목록
- **카테고리 탭**: 지정된 카테고리별 필터링

각 종목 카드를 탭하면 **Lot별 상세 수익률**이 펼쳐집니다.

### 카테고리 할당

Lot 행의 **전략** 드롭다운에서 카테고리 및 자동 전략을 할당할 수 있습니다.

## 7. 자산 관리

하단 **자산** 탭에서 접근합니다.

### 환전 탭

#### Wise CSV 업로드

2. **CSV 파일 선택** 버튼으로 업로드

- **총 투입 원화**: 저장된 모든 환전 기록의 원화 합계
- **현재 KRW 환산가**: 현재 Alpaca 계좌 총 자산 × 현재 환율
- **환차익/손실**: 두 값의 차이

### 세금 탭

| 항목 | 내용 |

## 8. 알림

하단 **알림** 탭에서 접근합니다.

### 알림 허용

**알림 수신** 토글에서 **허용** 버튼을 탭하면 브라우저 푸시 알림이 활성화됩니다.  
이후 아래 이벤트 발생 시 브라우저 알림을 받습니다.

| 이벤트 | 알림 내용 |
|--------|-----------|
| 목표가 도달 | "AAPL이 $200.00에 도달했습니다" |
| 주문 체결 | "AAPL 10주 매수 체결 @ $150.00" |
| 전략 자동 매도 | "AAPL 3주 자동 매도 (+20% 룰)" |

### 목표가 알림 설정

1. 종목 티커 입력
2. 목표 가격 입력
3. **이상** / **이하** 선택
4. **알림 추가**

서버가 실행 중인 동안 60초마다 가격을 확인하여 조건 충족 시 알림을 발송합니다.  
알림 발송 후 해당 알림은 자동으로 비활성화됩니다.

### 알림 내역

**내역** 탭에서 과거에 발송된 알림 이력을 확인할 수 있습니다.

## 9. 설정

하단 **설정** 탭에서 접근합니다.

### 카테고리 관리

포트폴리오에서 종목을 그룹화하는 사용자 정의 카테고리입니다.

1. 색상 선택 (8가지 프리셋)
2. 카테고리 이름 입력 후 **추가**
3. 포트폴리오 → 종목 카드의 Lot 행에서 카테고리 할당 가능
4. 포트폴리오에서 카테고리 탭으로 필터링 가능

### 매매 전략 관리

Lot에 자동 매도 전략을 설정합니다.

#### 전략 생성

1. 전략 이름 입력 후 **추가**
2. 해당 전략 카드를 탭해 펼치기
3. **수익률 %** (임계값)와 **매도 %** 입력 후 룰 추가

#### 예시: 성장주 전략

| 수익률 도달 | 원래 수량의 매도 비율 |
|------------|---------------------|
| +20% | 30% 매도 |
| +50% | 50% 매도 (이미 판 것 차감) |
| +70% | 100% 전량 매도 |
| -15% | 100% 손절 |

#### 전략 작동 방식

- 서버 실행 중 **30초마다** 전략이 적용된 Lot의 현재 수익률 체크
- 조건 충족 시 **자동 시장가 매도** 실행
- 체결 후 푸시 알림 발송
- 매도 수량은 **원래 Lot 수량 기준 누적 계산** (동일 조건 중복 실행 방지)

#### Lot에 전략 할당

포트폴리오 → 종목 카드 → Lot 행 → **전략** 드롭다운에서 선택

## 10. 주요 개념

### Lot (로트)

동일 종목이라도 **매수 시점이 다르면 별도 Lot으로 관리**합니다.

```
AAPL 보유:
  Lot 1: 2024-01-15 | 150.00에 5주 | 현재 +15.3%
  Lot 2: 2024-03-20 | 175.00에 3주 | 현재 -1.2%
```

- 매도 시 어느 Lot을 팔지 직접 선택 가능
- 세금 최적화에 활용 (수익 실현 시점 조절)
- 자동 전략도 Lot 단위로 적용

### 환율 기준

- 취득환율: 환전 당시 적용된 환율 (FX 기록에서 조회)
- 양도환율: 매도 시점의 현재 환율 (ExchangeRate-API)
- 두 환율의 차이로 환차익/손실이 계산됩니다

### 소수점 거래 (Fractional Shares)

- **정규장**: 금액($) 또는 소수점 수량(예: 0.5주) 매수 가능
- **프리/애프터마켓**: 정수 수량만 가능
- Alpaca 직접 거래 방식이라 거래소 규칙을 그대로 따릅니다

## 11. 자주 묻는 질문

**Q. 장 마감 중에도 앱을 써도 되나요?**  
A. 네. 지정가 예약 주문, 포트폴리오 확인, 알림 설정 등은 24시간 사용 가능합니다.

**Q. Alpaca Paper Trading 계좌란 무엇인가요?**  
A. 가상 $100,000으로 실제 시세로 주식 거래를 연습할 수 있는 모의투자 계좌입니다. 실제 돈은 없습니다.

**Q. 인기 종목이 업데이트되지 않아요.**  
A. FMP API 키 또는 일일 요청 한도 문제일 수 있습니다. 키를 확인해주세요.

**Q. 배당금이 표시되지 않아요.**  
A. 배당이 없는 종목(성장주 등)은 정상적으로 표시되지 않습니다. 배당주(AAPL, MSFT 등)에서 확인해주세요.

**Q. 실시간 차트에 선이 안 그려져요.**  
A. 장 외 시간에는 거래가 없어 실시간 데이터가 수신되지 않습니다. 장 중에 확인해주세요.

**Q. 자동 전략이 작동하지 않아요.**  
A. 서버(`npm run dev` 또는 `npm start`)가 실행 중이어야 합니다. 서버가 꺼지면 자동 매도가 중단됩니다.

**Q. 지인에게 소스를 공유하려면?**  
A. `.env.example`을 참고해 `.env` 파일을 새로 만들고 본인의 API 키를 입력하면 됩니다.  
```bash
cp .env.example .env
# 각 키 입력 후
npm install
npx prisma migrate dev
npm start
```
